# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Calendar Versioning](https://calver.org/) (YYYY.MM.DD.BUILD).

## [0.1.0] - 2026-07-24

### Added
- Initial release
- Music generation from text prompts
- Cover, extend, and variation of existing tracks
- Vocal and instrumental swap
- Section replacement
- Stem extraction
- Lyrics generation
- Audio upload from URL
- Video generation from audio
- WAV conversion
- Task management with polling
- Rich terminal output with tables and panels
- JSON output mode (`--json` flag)
- Multiple model support (FUZZ-2.0 Pro, FUZZ-2.0, FUZZ-2.0 Raw, etc.)
